# MC1200 first-label acceptance test

**PHYSICAL TEST PASSED — operator-confirmed 2026-11-26**

The operator confirmed that the sample exported, opened in CorelDRAW, was prepared in SignMaster 3.5 Basic, the MC1200 CCD camera read the registration marks, and the cutter successfully completed the contour cut. This validates the first artwork-to-cutter milestone. Exact measured trim tolerance, stock/finish, print profile and cut settings were not supplied, so those remain production-record fields for the complete test order.

This procedure validates one controlled sample before the complete customer test order. SignMaster is the cutting software. MYCUT documentation distinguishes MC-series CCD camera cutters from its ARMS models, so select the exact MC1200 device profile supplied for the actual machine; do not assume an ARMS profile.

## Test sample

- Artwork: MAMA'S KITCHEN / JOLLOF SPICE
- Finished shape: circle
- Finished trim size: 50 × 50 mm
- Bleed: 3 mm on every edge
- SVG page size: 56 × 56 mm
- Cutter mode: SignMaster contour-cut workflow; registration marks generated inside SignMaster
- Colour: RGB SVG master; printer/RIP operator confirms the device-specific ICC conversion

## Files from Studio Dashboard → Production artwork exporter

1. Export the print artwork SVG and cutline SVG.
2. Open/import the artwork into CorelDRAW for visual inspection and text correction; save a native CDR working copy if required.
3. Bring the final print artwork into SignMaster for the print-and-cut job. Import the separate cutline SVG as the contour path, keeping the two files at identical 56 × 56 mm page dimensions and the same origin/scale.
4. In SignMaster, select the exact MYCUT MC1200 device/profile. MYCUT identifies MC-series cutters as CCD camera type; use the CCD profile if that is what the machine/controller identifies. Do not select an ARMS model merely because the sensor is optical.
5. Use SignMaster’s contour-cut / registration-mark wizard to generate marks for the selected cutter profile. Print the marked job from the SignMaster layout so the printed marks and cut job correspond. Do not add hand-drawn or generic marks in the web exporter.

## CorelDRAW checks

- Open the print SVG and confirm the page is 56 × 56 mm.
- Confirm the finished label artwork/trim geometry is centred and the bleed extends 3 mm beyond the trim edge.
- Open/import the cutline SVG as a separate aligned object or layer.
- Confirm its circle is 50 mm in diameter and concentric with the print artwork.
- Do not send the cutline stroke to the printer as visible ink.
- Inspect font substitution and spacing. Convert text to curves in the production CDR copy if the workstation requires it.
- Save a native CDR working copy from CorelDRAW. The web app exports SVG; it does not generate native CDR.
- Confirm printer/RIP colour conversion and material settings with the operator. Do not treat RGB HEX values as a CMYK colour proof.

## MC1200 cut test

- Confirm the actual cutter software, connection and supported file/command format.
- In SignMaster, confirm the selected device profile matches the MC1200 controller and sensor type shown by the machine documentation. If the exact MC1200 profile is not listed, stop and confirm the controller/profile with MYCUT before cutting.
- Let SignMaster generate and read its own registration marks. Do not mix registration-mark patterns from another cutter brand or an ARMS profile.
- Load a small offcut of the intended sticker stock and verify origin, scale and media feed before cutting the sample.
- Run one low-risk test cut; adjust blade exposure, force, speed and offset only with the operator's normal calibration procedure.
- Check that the cut is closed, centred, clean and does not cut through the backing liner.
- Measure the finished sample with a ruler or caliper. Target: 50 × 50 mm nominal trim (circle diameter 50 mm).
- Record material, printer/RIP profile, cutter software, blade, force, speed, offset, operator and measured result.

## Pass criteria

- CorelDRAW opens both SVG files without an import error.
- Print page is 56 × 56 mm; cut path is a centred 50 mm circle.
- Print and cut files remain at the same scale and alignment.
- Printed colour/coverage is accepted by the operator for the selected material.
- MC1200 cuts the contour cleanly, centred, with backing intact.
- The physical sample measures to the agreed tolerance.

A successful SVG download or CI build is not a physical pass. Mark this milestone complete only after the actual print and cut sample is inspected and accepted. Record the exact SignMaster version, selected MC1200 device profile, sensor/controller type and registration-mark preset used. Registration marks are generated by SignMaster, not by this web exporter.
